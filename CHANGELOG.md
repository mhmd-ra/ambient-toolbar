# Changelog

## 1.2.0 (2026-10-14)
- New default look, calibrated to blend with Ambient light for YouTube's glow (natural colors, top 40% of the frame, softer gradient, 60% brightness).
- New: Color picking (Natural / Vivid) and Remove black bars (letterbox detection).
- New: Import settings page. It reads an Ambient light for YouTube settings export and converts it, or an Ambient Toolbar settings file. Opens in a tab, because Firefox closes popups when a file picker opens.
- New: Export settings to a file (popup → Import / Export…).
- New: **Recommended** preset and `presets/` folder with the tested pair of settings for Ambient light for YouTube and Ambient Toolbar.
- Fixed a crash in Natural color mode.

## 1.1.0 (2026-10-14)
- New settings panel styled after Ambient Light for YouTube, with collapsible sections and an Advanced switch.
- New settings: Blur, Edge size, Spread fade, Color zones, Contrast, Color temperature, Toolbar shade, Text & icons.
- Presets: Default, Subtle, Vivid, Cinema, Gaming, Solid.
- Settings are also available from Add-ons → Options.

## 1.0.0 (2026-10-14)
- First release.
- Gradient glow (flicker-free 1-pixel strip with double buffering) and a smooth solid-color mode.
- Smooth color fading, vivid color picking, saturation and brightness settings.
- Keeps the color while paused, updates on seek, restores the theme when leaving the video.
- Works on watch pages and Shorts.
