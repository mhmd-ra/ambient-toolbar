# Security Policy

## Supported versions

Only the latest release on [addons.mozilla.org](https://addons.mozilla.org/firefox/addon/ambient-toolbar-for-youtube/) receives fixes.

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/mhmd-ra/ambient-toolbar/security/advisories/new),
not as a public issue.

Include the add-on version, your Firefox version, and steps to reproduce. You can expect a first reply within a week.

## Scope

The add-on runs only on youtube.com, requests only the `theme` and `storage` permissions, and makes no network requests. Reports that are especially useful:

- Ways a web page could read or change the add-on's settings, or affect other tabs or windows
- Unsafe handling of imported settings files
- Anything that would let the add-on send data off the device
