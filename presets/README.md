# Recommended settings

A tested pair of settings files, the ones used for the screenshots. Import one into each add-on and the toolbar glow blends with the glow around the video.

| File | Import into | How |
|---|---|---|
| [`ambient-light-settings.json`](ambient-light-settings.json) | [Ambient light for YouTube](https://github.com/WesselKroos/youtube-ambilight) | Its settings panel on a YouTube video → import |
| [`ambient-toolbar-settings.json`](ambient-toolbar-settings.json) | Ambient Toolbar | Toolbar popup → **Import / Export…** → choose the file |

Ambient Toolbar also has these settings built in as the **Recommended** preset, so you can skip its file and click that instead.
